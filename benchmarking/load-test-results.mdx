# Load Test Results

## Batch-Poll Consumer Benchmark (2026-09-28)

Test environment: kind K8s cluster, single worker node.

### Infrastructure

| Component | Config |
|-----------|--------|
| Goose | 1 pod, no resource limits, distroless image |
| Kafka | 1 broker (apache/kafka:3.7.1 KRaft), 1 partition |
| Mock HTTP | 3 replicas (configurable delay) |

### Results

|--------|-------|

### Comparison with Previous Baseline (2026-07-13)

| Metric | Old (single-poll) | New (batch-poll) | Improvement |
|--------|-------------------|------------------|-------------|
| Throughput @50ms | 2,500/s | ~4,000/s | **+60%** |
| Memory | 30 MiB | 13-23 MiB | **-23% to -57%** |
| Message drops | 1,058 | 0 | **100% fixed** |
| Max connections | 10 (hardcoded) | 250 (auto-matched) | **25x** |
