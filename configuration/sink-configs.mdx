# Sink Configurations

All non-HTTP sink types are selected via `SINK_TYPE`. Each has its own set of environment variables.

## Sink Type Selection

| `SINK_TYPE` | Sink | Required Env Vars |
|-------------|------|-------------------|
| `http` (default) | HTTP REST | `SINK_HTTP_SERVICE_URL` |
| `grpc` | gRPC | `SINK_GRPC_SERVICE_URL`, `SINK_GRPC_METHOD` |
| `mongodb` | MongoDB | `SINK_MONGO_CONNECTION_URL`, `SINK_MONGO_DATABASE`, `SINK_MONGO_COLLECTION` |
| `postgresql` | PostgreSQL | `SINK_SQL_CONNECTION_URL`, `SINK_SQL_TABLE_NAME` |
| `redis` | Redis | `SINK_REDIS_ADDRESSES` |

## gRPC Sink

| Env Var | Default | Description |
|---------|---------|-------------|
| `SINK_GRPC_SERVICE_URL` | _(required)_ | gRPC server address |
| `SINK_GRPC_METHOD` | _(required)_ | gRPC method (e.g., `events.OrderService/ProcessOrder`) |
| `SINK_GRPC_TIMEOUT_MS` | `10000` | gRPC call timeout |
| `SINK_GRPC_TLS_ENABLED` | `false` | Enable TLS |
| `SINK_GRPC_AUTH_TYPE` | `none` | `none` or `bearer` |
| `SINK_GRPC_AUTH_TOKEN` | _(empty)_ | Bearer token |

<Callout type="info">
gRPC uses protobuf natively. If Kafka has raw protobuf bytes, goose passes them directly — no Stencil or schema registry needed.
</Callout>

### gRPC Error Classification

| gRPC Code | Classification | Action |
|-----------|---------------|--------|
| `INVALID_ARGUMENT`, `NOT_FOUND`, `ALREADY_EXISTS`, `PERMISSION_DENIED` | Permanent | DLQ |
| `UNAVAILABLE`, `DEADLINE_EXCEEDED`, `RESOURCE_EXHAUSTED` | Transient | Retry |

## MongoDB Sink

| Env Var | Default | Description |
|---------|---------|-------------|
| `SINK_MONGO_CONNECTION_URL` | _(required)_ | MongoDB connection URL |
| `SINK_MONGO_DATABASE` | _(required)_ | Database name |
| `SINK_MONGO_COLLECTION` | _(required)_ | Collection name |
| `SINK_MONGO_MODE` | `insert` | `insert` or `upsert` |
| `SINK_MONGO_PRIMARY_KEY` | _(empty)_ | Primary key field for upsert |
| `SINK_MONGO_AUTH_ENABLED` | `false` | Enable auth |
| `SINK_MONGO_AUTH_USERNAME` | _(empty)_ | Auth username |
| `SINK_MONGO_AUTH_PASSWORD` | _(empty)_ | Auth password |
| `SINK_MONGO_AUTH_DB` | `admin` | Auth database |
| `SINK_MONGO_CONNECT_TIMEOUT_MS` | `5000` | Connection timeout |

### MongoDB Error Classification

| Error | Action |
|-------|--------|
| Duplicate key (code 11000) | DLQ (non-retryable) |
| Connection error | Retry → DLQ if exhausted |
| Invalid JSON | DLQ (non-retryable) |

## PostgreSQL Sink

| Env Var | Default | Description |
|---------|---------|-------------|
| `SINK_SQL_CONNECTION_URL` | _(required)_ | PostgreSQL connection URL |
| `SINK_SQL_TABLE_NAME` | _(required)_ | Table name |
| `SINK_SQL_MODE` | `insert` | `insert` or `upsert` |
| `SINK_SQL_PRIMARY_KEYS` | _(empty)_ | Comma-separated primary key fields for upsert |
| `SINK_SQL_CONNECTION_POOL_MAX` | `10` | Max DB connections |
| `SINK_SQL_CONNECT_TIMEOUT_MS` | `10000` | Connection timeout |

<Callout type="info">
JSON message fields become table columns automatically. Upsert mode uses `ON CONFLICT (pk) DO UPDATE SET`.
</Callout>

### PostgreSQL Error Classification

| Error | Action |
|-------|--------|
| Duplicate key (SQL state 23505) | DLQ (non-retryable) |
| Connection error | Retry → DLQ if exhausted |
| Invalid JSON | DLQ (non-retryable) |

## Redis Sink

| Env Var | Default | Description |
|---------|---------|-------------|
| `SINK_REDIS_ADDRESSES` | _(required)_ | Comma-separated Redis addresses |
| `SINK_REDIS_PASSWORD` | _(empty)_ | Redis password |
| `SINK_REDIS_DATABASE` | `0` | Redis database number |
| `SINK_REDIS_DATA_TYPE` | `keyvalue` | `keyvalue`, `hashset`, or `list` |
| `SINK_REDIS_KEY_TEMPLATE` | _(empty)_ | Key template (e.g., `payment:%s`) |
| `SINK_REDIS_KEY_FIELD` | _(empty)_ | JSON field to extract key value from |
| `SINK_REDIS_HASH_FIELD` | _(empty)_ | Hash field name (for hashset mode) |
| `SINK_REDIS_DEPLOYMENT_TYPE` | `standalone` | `standalone` or `cluster` |
| `SINK_REDIS_TTL_TYPE` | `DISABLE` | `DISABLE` or `EX` |
| `SINK_REDIS_TTL_VALUE` | `0` | TTL in seconds |

### Redis Data Types

| Type | Redis Command | Example |
|------|--------------|---------|
| `keyvalue` | `SET key value [EX ttl]` | `SET payment:PAY-001 {"amount":500}` |
| `hashset` | `HSET key field value` | `HSET payment:PAY-001 data {"amount":500}` |
| `list` | `LPUSH key value` | `LPUSH payments {"amount":500}` |
