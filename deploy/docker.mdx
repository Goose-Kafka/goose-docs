# Docker

## Pull

```bash
docker pull ghcr.io/goose-kafka/goose:v1.1.0
```

## Run

```bash
docker run -e SOURCE_KAFKA_BROKERS=kafka:9092 \
           -e SOURCE_KAFKA_TOPIC=events \
           -e SOURCE_KAFKA_CONSUMER_GROUP_ID=goose \
           -e SINK_HTTP_SERVICE_URL=http://service:8080/api \
           -e INPUT_SCHEMA_DATA_TYPE=json \
           ghcr.io/goose-kafka/goose:v1.1.0
```

## With Protobuf

```bash
docker run -e SOURCE_KAFKA_BROKERS=kafka:9092 \
           -e SOURCE_KAFKA_TOPIC=events \
           -e SOURCE_KAFKA_CONSUMER_GROUP_ID=goose \
           -e SINK_HTTP_SERVICE_URL=http://service:8080/api \
           -e INPUT_SCHEMA_DATA_TYPE=protobuf \
           -e SCHEMA_REGISTRY_ENABLED=true \
           -e SCHEMA_REGISTRY_URL=http://stencil:8080/descriptors/events.OrderEvent/latest \
           -e SCHEMA_REGISTRY_PROTO_CLASS=events.OrderEvent \
           ghcr.io/goose-kafka/goose:v1.1.0
```

## Image Details

- Base: `gcr.io/distroless/static-debian12:nonroot`
- Size: ~33MB
- Architecture: amd64 + arm64 (multi-arch)
- No shell (distroless)
- Runs as nonroot user (UID 65532)
- Signed with Cosign (sigstore keyless)

## Image Verification

Verify the image signature before deploying:

```bash
cosign verify ghcr.io/goose-kafka/goose:v1.1.0
```

## SBOM

Each release includes a Software Bill of Materials (SBOM) in SPDX JSON format:
- Available on [GitHub Releases](https://github.com/Goose-Kafka/goose/releases) as `goose-sbom.spdx.json`
- Generated by [Syft](https://github.com/anchore/syft)
- Lists all dependencies, versions, and licenses

## Vulnerability Scanning

Trivy scans run on every CI build and release:
- Container image scan (OS packages + Go binaries)
- Source code filesystem scan
- Results uploaded to GitHub Security tab
- HIGH and CRITICAL vulnerabilities are reported (non-blocking)
